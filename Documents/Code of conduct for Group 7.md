**Code of conduct for Group 7**



This code of conduct applies to all team members in group 7 for development operations project. These regulations are to help members collaborate better and set standard workplace behavior.



**Purpose of this code**

This code explains how we expect members of Group 7 to behave while contributing to this team. It also clarifies what we consider respectful, ethical, and professional conduct.

All members are expected to –

* Treat other team members with respect
* Communicate clearly and actively
* Listen to and consider other members’ ideas and opinions
* Complete assigned tasks within agreed deadlines
* Inform the team as early as possible if a task is delayed
* Participate in meetings, planning, discussions, and reviews
* Keep GitHub up to date
* Ask for help when facing difficulties
* Respect decision made by other members
* Give appropriate credit to other members for their work



**Communication**

* Team members are expected to communicate clearly in agreed channels for project-related discussions and important decisions should be recorded or pinned



**GitHub practices**

* Team members should not push directly to master branch without consulting other members
* Team members should only work in their designated branches and make pull request to develop branch
* Team members should avoid modifying another members' branches without agreement
* Create clear commit messages
* Review code and changes before submitting pull request



**Handling disagreements**

* Disagreements should be handled with evidence based reasoning
* Should be resolve with respect
* Personal disagreements should not interfere with the project
