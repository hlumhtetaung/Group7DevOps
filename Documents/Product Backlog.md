# Population Reporting System (Product Owner)

## Product Backlog — Code Review 1

# Epic A — Generate Country Reports

## US-A1 — All Countries in the World

**User Story:** As an organization user, I want to view all countries in the world ordered from largest population to smallest so that I can compare country populations worldwide.

**Priority:** Must **Story Points:** 3 **Status:** To Do

**Acceptance Criteria**

-  All countries are included.

-  Report contains Code, Name, Continent, Region, Population and Capital.

-  Results are ordered by population from largest to smallest.

## US-A2 — Countries in a Continent

**User Story:** As an organization user, I want to view all countries in a selected continent ordered from largest population to smallest so that I can compare country populations within that continent.

**Priority:** Must **Story Points:** 5 **Status:** To Do

**Acceptance Criteria**

-  A continent can be specified.

-  Only countries in the selected continent are included.

-  Report contains Code, Name, Continent, Region, Population and Capital.

-  Results are ordered by population from largest to smallest.

## US-A3 — Countries in a Region

**User Story:** As an organization user, I want to view all countries in a selected region ordered from largest population to smallest so that I can compare country populations within that region.

**Priority:** Must **Story Points:** 5 **Status:** To Do

**Acceptance Criteria**

-  A region can be specified.

-  Only countries in the selected region are included.

-  Report contains Code, Name, Continent, Region, Population and Capital.

-  Results are ordered by population from largest to smallest.

## US-A4 — Top N Countries in the World

**User Story:** As an organization user, I want to provide N and view the top N populated countries in the world so that I can identify the most populated countries worldwide.

**Priority:** Should **Story Points:** 5 **Status:** To Do

**Acceptance Criteria**

-  The user can provide N.

-  Report contains Code, Name, Continent, Region, Population and Capital.

-  The requested top N countries are returned.

-  Results are ordered by population from largest to smallest.

## US-A5 — Top N Countries in a Continent

**User Story:** As an organization user, I want to provide N and view the top N populated countries in a selected continent so that I can identify the most populated countries within that continent.

**Priority:** Should **Story Points:** 5 **Status:** To Do

**Acceptance Criteria**

-  The user can provide N and specify a continent.

-  Only countries in the selected continent are considered.

-  Report contains Code, Name, Continent, Region, Population and Capital.

-  The requested top N countries are returned in descending population order.

# Epic F — Generate Language Report

## US-F1 — Language Population Report

**User Story:** As an organization user, I want to view the number of people who speak Chinese, English, Hindi, Spanish and Arabic, ordered from greatest to smallest and including their percentage of the world population, so that I can compare the populations of these languages.

**Priority:** Should **Story Points:** 8 **Status:** To Do

**Acceptance Criteria**

-  The report includes Chinese, English, Hindi, Spanish and Arabic.

-  The number of speakers is calculated using country population and language percentage data.

-  Each language's percentage of the world population is displayed.

-  Languages are ordered from greatest to smallest by number of speakers.
